# L04　1.2.1 空間中的點、直線與空間向量（練習課）

> 課型：**練習課**｜工作紙 1.2.1 網頁版（共 8 份）｜教材範圍：1.2.1 空間中的點、直線與空間向量。題目取自同名工作紙（原設計 50 分鐘），這裏依練習課技能編成 40 分鐘：每層每關先做第 1 題，第 2 題放在第 4 階段。學生表現一律為「預期情況」，實際請依課堂證據調整。

## A. 課堂基本資料

- 年級：高中選修（相當於中五）
- 課題：空間中的點、直線與空間向量
- 課時：40分鐘
- 課型：練習課
- 核心學習目標：能寫出直線的方向向量，判斷兩直線平行、垂直，求兩直線所成的角，並判斷異面直線、求公垂線段長
- 先備知識：1.1.3 坐標運算與建系；1.2.1 新課內容
- 教學重點：方向向量；兩直線所成角的餘弦要取絕對值；公垂線段的兩個垂直條件
- 學習難點：向量夾角與直線所成角的分別；含兩個參數的公垂線段
- 本節刻意不教：平面的法向量（1.2.2）

## D. 典型錯誤分析

以下均為「預期錯誤」（未取自真實學生作答），教師可換成當堂收集、去識別化的例子。

### 4-1 抓錯偵探：這個角可以嗎？

- 題目：方向向量 \((1,0,-1)\) 與 \((0,1,1)\)，求兩直線所成的角。
- 錯誤示例：\(\cos\langle \boldsymbol{v}_{1},\boldsymbol{v}_{2}\rangle =\frac{-1}{\sqrt{2}\times\sqrt{2}}=-\frac{1}{2}\) → 所以兩直線所成的角是 120°（錯在第 2 步）
- 可能原因：概念錯誤：直線所成的角不大於 90°，餘弦要取絕對值。
- 診斷問題：這個解法哪一步開始出現問題？為甚麼這樣計算不正確？怎樣檢查答案是否合理？
- 教師引導方式：不公開學生身份；先讓學生指出步驟，再追問成因，最後由學生修正。
- 正確做法：\(\cos\theta=\frac{1}{2}\)，所成的角是 60°
- 修正後練習：3-1 B 層若 \(E\) 改為 \(C_{1}\)，\(AC_{1}\) 與 \(BD_{1}\) 所成角的餘弦是？

### 4-2 再抓一次：要垂直幾條直線？

- 題目：3-1 C 層的兩條直線，\(P(1,t,t)\) 在 \(l_{1}\) 上，\(Q(s,1,-s)\) 在 \(l_{2}\) 上，求公垂線段 \(PQ\) 的長。
- 錯誤示例：只列 \(\overrightarrow{PQ}\perp l_{1}\)，得 \(s=1-2t\) → 取 \(t=0\)，\(s=1\)，\(\vert PQ\vert =\sqrt{2}\)（錯在第 1 步）
- 可能原因：程序錯誤：公垂線段要同時垂直兩條直線，還要 \(\overrightarrow{PQ}\perp l_{2}\)。
- 診斷問題：這個解法哪一步開始出現問題？為甚麼這樣計算不正確？怎樣檢查答案是否合理？
- 教師引導方式：不公開學生身份；先讓學生指出步驟，再追問成因，最後由學生修正。
- 正確做法：兩條方程聯立：\(t=s=\frac{1}{3}\)，\(\vert PQ\vert =\frac{2\sqrt{3}}{3}\)
- 修正後練習：3-1 B 層若 \(E\) 改為 \(C_{1}\)，\(AC_{1}\) 與 \(BD_{1}\) 所成角的餘弦是？

## E. 出口題及評估

- 出口題：棱長 2 的正方體（\(D\) 為原點），\(E\) 是 \(A_{1}B_{1}\) 中點。(1) 寫出 \(\overrightarrow{AE}\) 與 \(\overrightarrow{BC_1}\)；(2) 求 \(AE\) 與 \(BC_{1}\) 所成角的餘弦。
- 參考答案：(1) \((0,1,2)\)，\((-2,0,2)\)；(2) \(\frac{\sqrt{10}}{5}\)
- 時間：2～3 分鐘，獨立完成。

| 結果 | 判準及下一節安排 |
|------|------|
| 已掌握 | 兩小題全對，餘弦取正值並化簡 → 進入 1.2.2 法向量，可做第二關 C 層 |
| 部分掌握 | 方向向量對，但餘弦取了負值或計算有誤 → 下一節課首做一題「向量夾角與直線所成角」比較 |
| 尚未掌握 | 寫不出兩個向量的坐標 → 小組重做 1.1.3 的讀點，再做第一關 A 層 |

## G. 螺旋設計與學習追蹤

**本課型路徑**：能力提升螺旋：基礎辨識 → 獨立應用 → 變式比較 → 綜合解難

### 2. 螺旋深化路徑

- 學生已經理解：已學過方向向量、直線所成的角和公垂線段的定義。
- 本次新增的理解：分清「向量的夾角」與「直線所成的角」：直線沒有方向，所以餘弦取絕對值；公垂線段要同時滿足兩個垂直條件。
- 之後會延伸到：1.2.2 引入法向量；1.2.3、1.2.4 用同一套做法求線面角和面面角。

### 3. 分層學習任務

| 學生 | 任務層 | 支持方式 | 完成後 |
|------|------|------|------|
| 基礎薄弱 | A 層 | 提示階梯、附圖與第一步線索 | 嘗試 B 層 |
| 一般 | B 層 | 必要時看提示 | 嘗試 C 層 |
| 能力較高 | C 層 | 少提示，要求解釋或比較 | 自編變式題 |

分層指任務與支持不同，不是固定學生標籤；學生可依表現隨時換層。
