# L05　1.2.2 空間中的平面與空間向量（練習課）

> 課型：**練習課**｜工作紙 1.2.2 網頁版（共 8 份）｜教材範圍：1.2.2 空間中的平面與空間向量。題目取自同名工作紙（原設計 50 分鐘），這裏依練習課技能編成 40 分鐘：每層每關先做第 1 題，第 2 題放在第 4 階段。學生表現一律為「預期情況」，實際請依課堂證據調整。

## A. 課堂基本資料

- 年級：高中選修（相當於中五）
- 課題：空間中的平面與空間向量
- 課時：40分鐘
- 課型：練習課
- 核心學習目標：能求平面的法向量，用方向向量與法向量判斷線面、面面的平行與垂直，並用三垂線定理證明線線垂直
- 先備知識：1.2.1 方向向量；1.1.3 數量積為 0；1.2.2 新課內容
- 教學重點：求法向量要列兩條方程並代回檢查；v 與 n 的關係對應哪一種位置關係
- 學習難點：v⊥n 是平行（或在平面內）而不是垂直；三垂線定理中的直線必須在平面內
- 本節刻意不教：用法向量求角與距離（1.2.3–1.2.5）

### 第 1 階段　0–6 分鐘　診斷起步題（簡報：暖身診斷：你在哪一關？；螺旋：基礎辨識）

## D. 典型錯誤分析

以下均為「預期錯誤」（未取自真實學生作答），教師可換成當堂收集、去識別化的例子。

### 4-1 抓錯偵探：是垂直嗎？

- 題目：\(\boldsymbol{v}=(2,1,0)\)，\(\boldsymbol{n}=(1,-2,3)\)，判斷直線 \(l\) 與平面 \(\alpha\) 的關係。
- 錯誤示例：\(\boldsymbol{v}\cdot\boldsymbol{n}=2-2+0=0\) → 所以 \(l\perp\alpha\)（錯在第 2 步）
- 可能原因：概念錯誤：\(\boldsymbol{v}\perp\boldsymbol{n}\) 表示直線平行平面或在平面內。
- 診斷問題：這個解法哪一步開始出現問題？為甚麼這樣計算不正確？怎樣檢查答案是否合理？
- 教師引導方式：不公開學生身份；先讓學生指出步驟，再追問成因，最後由學生修正。
- 正確做法：\(l\parallel\alpha\) 或 \(l\subset\alpha\)；再檢查 \(l\) 上一點
- 修正後練習：直線方向 \((1,k,2)\) 與上題的平面可能垂直嗎？\(\boldsymbol{v}\cdot\boldsymbol{n}=0\) 時 \(k\) 是多少？

### 4-2 再抓一次：方程夠了嗎？

- 題目：平面過 \(A(1,0,0)\)，\(B(0,2,0)\)，\(C(0,0,2)\)，求一個法向量。
- 錯誤示例：由 \(\boldsymbol{n}\cdot\overrightarrow{AB}=0\) 得 \(-x+2y=0\) → 取 \(x=2\)，\(y=1\)，\(z=0\)，\(\boldsymbol{n}=(2,1,0)\)（錯在第 2 步）
- 可能原因：程序錯誤：只用了一條方程，沒有用 \(\boldsymbol{n}\cdot\overrightarrow{AC}=0\)。
- 診斷問題：這個解法哪一步開始出現問題？為甚麼這樣計算不正確？怎樣檢查答案是否合理？
- 教師引導方式：不公開學生身份；先讓學生指出步驟，再追問成因，最後由學生修正。
- 正確做法：再由 \(-x+2z=0\) 得 \(z=1\)，\(\boldsymbol{n}=(2,1,1)\)
- 修正後練習：直線方向 \((1,k,2)\) 與上題的平面可能垂直嗎？\(\boldsymbol{v}\cdot\boldsymbol{n}=0\) 時 \(k\) 是多少？

## E. 出口題及評估

- 出口題：平面 \(\alpha\) 過 \(A(1,0,0)\)，\(B(0,2,0)\)，\(C(0,0,3)\)；直線 \(l\) 的方向向量是 \((2,-2,-3)\)。(1) 求 \(\alpha\) 的一個法向量；(2) 判斷 \(l\) 與 \(\alpha\) 的關係，還要檢查甚麼？
- 參考答案：(1) \((6,3,2)\)；(2) 數量積為 0，\(l\parallel\alpha\) 或 \(l\subset\alpha\)，要檢查 \(l\) 上一點
- 時間：2～3 分鐘，獨立完成。

### 2. 螺旋深化路徑

- 學生已經理解：已學過法向量的定義和三垂線定理。
- 本次新增的理解：法向量把「平面」變成一個向量：線面、面面關係都變成兩個向量平行或垂直的問題；並養成求完代回檢查的習慣。
- 之後會延伸到：1.2.3 用法向量求線面角；1.2.4 求面面角；1.2.5 求點面距離。

### 3. 分層學習任務

| 學生 | 任務層 | 支持方式 | 完成後 |
|------|------|------|------|
| 基礎薄弱 | A 層 | 提示階梯、附圖與第一步線索 | 嘗試 B 層 |
| 一般 | B 層 | 必要時看提示 | 嘗試 C 層 |
| 能力較高 | C 層 | 少提示，要求解釋或比較 | 自編變式題 |

分層指任務與支持不同，不是固定學生標籤；學生可依表現隨時換層。

### 5. 學習證據追蹤

- 出口題（當堂）：見 E 節。
- 延遲檢測（約一週後，不提前通知、不先複習、不計分）：平面過 \(A(2,0,0)\)，\(B(0,1,0)\)，\(C(0,0,2)\)；直線的方向向量是 \((1,2,1)\)。求平面的一個法向量，並判斷直線與平面的關係。　答案：\((1,2,1)\)；方向向量與法向量平行，直線垂直平面
